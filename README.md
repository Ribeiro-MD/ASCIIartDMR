# ASCII Art DMR

Converte qualquer imagem em ASCII art diretamente no browser — com caracteres, cores e ajustes personalizáveis.

**🔗 Experimenta aqui: [ribeiro-md.github.io/ASCIIartDMR](https://ribeiro-md.github.io/ASCIIartDMR/)**

---

## O que podes fazer

- **Carregar imagens**
- 
- **Ajustar:**:
  - **Largura** — de 20 a 340 caracteres por linha
  - **Contraste** e **Brilho**
- **Escolher os caracteres**:
  - `.:-=+*#%@` (simples)
  - **Detalhado** (70 caracteres, mais definição)
  - `░▒▓█` (blocos)
  - `01` (estilo binário)
  - **Meus…** — escreves o teu próprio conjunto
- **Cores**:
  - **Cores** — cada caractere fica com a cor original da imagem
  - **Monocor** — tudo numa só cor à tua escolha (seletor + código HEX)
- **Inverter** claro/escuro e alternar **Fundo preto**
- **Copiar** o resultado para a área de transferência com um clique

## Como usar


1. Carrega uma imagem.
2. Mexe nos sliders e nas opções até ficar como queres.
3. Clica em **Copiar** e cola onde quiseres.

## Detalhes

- Tudo num só ficheiro: `index.html` (HTML + CSS + JavaScript, sem dependências)
- Corre 100% no browser — as imagens **não são enviadas** para lado nenhum
